This app connects to an STM32 Black Pill running the betacrawler firmware over USB.

To connect:

  1. Plug the board into a USB port.
  2. Click Connect.
  3. Select the board in your browser's device picker.

Once connected, use Configuration to view and change device settings, Controller to watch the live radio link and set up the drive mixer, Modes for the arming switch, and Terminal for direct command-line access to the device for debugging. Some pages will be greyed out until a device is connected.

Need help? See the Help page for troubleshooting tips.
