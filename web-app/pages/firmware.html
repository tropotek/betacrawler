Getting into DFU mode

Flashing does this by itself, so none of it is part of the normal path. It matters when the firmware on the board is broken, and when you want the board left in DFU for an external tool rather than written to here.

By hand, which works whatever state the firmware is in:

  1. Hold the BOOT0 button down.
  2. Tap NRST and release it.
  3. Release BOOT0.

The board then disappears as a serial port and shows up as a DFU device instead — pick it below, and the badge at the top of this page turns amber. This page keeps working while disconnected, which is the whole point: a board that needs re-flashing often can't be talked to.

Advanced: flash a local file
Nothing verifies this file matches your board. A bundled image above is checksummed against the manifest; a file you pick is only sanity-checked for being a raw firmware binary at all. Flashing the wrong one leaves the board unbootable until you re-flash it (BOOT0 + NRST still works, so this is recoverable — just tedious).

For a locally built image this is firmware/.pio/build/<env>/firmware.bin — the .bin, not the .elf or .hex beside it.
